# LEGION — Tiny armies. Epic conquests.

An original mobile-first, ancient-warfare strategy game. Drag from your teal stronghold to a destination, grow armies, capture territory, and use battle abilities.

This `gh-pages` branch is a standalone website. The `main` branch and GitHub profile are unchanged.

## Play

The intended GitHub Pages address is https://baney75.github.io/baney75/ once Pages is enabled and deployment has succeeded.

To activate Pages, open this repository's Settings → Pages, choose **Deploy from a branch**, select **gh-pages** and **/ (root)**, and save.

## Features

- Eight campaign battles, medals, and three selectable factions.
- Infantry, archers, cavalry, and rival armies.
- Arrow rain, War cry, Rally, and fortification.
- Random quick battles and free-ability sandbox mode.
- Touch and mouse controls, portrait and landscape layouts.
- Synthesized sound, reduced effects, and local campaign/battle saves.

## Development

There are no runtime libraries, external artwork downloads, accounts, analytics, or build requirements. Serve this directory with any static web server. All game logic and assets are contained in index.html and src/.

Progress belongs to the browser and website origin where you play. Moving between a local file, a preview URL, and GitHub Pages does not transfer saves automatically.
